# YOUR NAME Portfolio

A dark, cinematic single-page portfolio for an independent brand and web designer working with SaaS and AI companies.

## Included

- Full-screen hero with animated orange-to-red gradient wave and cursor response
- Light Selected Works section with mosaic previews and four placeholder project rows
- Services grid with eight services and hover emphasis
- Three-part Strategy, Identity, and Launch process section
- About section with placeholder outcomes, approach copy, portrait placeholder, and personality tags
- Staggered testimonial cards with placeholder identities and quotes
- Animated Get in Touch call to action and structured footer
- Responsive layouts for desktop, tablet, and mobile
- Reduced-motion behavior for gradient, parallax, marquee, and entrance animation
- SEO title, description, Open Graph, and Twitter metadata

## Content placeholders

The page intentionally uses `YOUR NAME`, placeholder companies, placeholder quotes, placeholder metrics, placeholder email links, and placeholder social links until real content is supplied.

## Reference values

The following values from the build prompt were implemented as visual estimates rather than measured from the reference site:

- Light section background: `#f4f4f4`
- Orange-red gradient: `#fc7814` → `#ca2708` → `#831e00`
- Hairlines: low-opacity white and black borders
- Display type: heavy, tightly tracked sans-serif using the project’s existing General Sans setup
- Accent type: Georgia italic for highlighted words
- Hero and CTA gradient animation: CSS layered gradient fallback with cursor response in the hero
- Section heading transitions and card choreography: GSAP ScrollTrigger entrance reveals
- Testimonial arrangement: responsive staggered absolute positioning

Replace the placeholders before publishing the portfolio.
