# Daksh Shastri — Portfolio

A personal portfolio for frontend developer Daksh Shastri, built with Next.js,
React, TypeScript, and GSAP. The site uses a restrained editorial layout to
present selected projects, experience, skills, achievements, and contact links.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build and lint

```bash
npm run build
npm run lint
```

## Notes

- Project panels are illustrative HTML/CSS previews rather than screenshots of
  the live applications.
- The About section focuses on education, experience, and skills.
- The navigation menu is keyboard accessible, and motion respects the
  `prefers-reduced-motion` setting.
